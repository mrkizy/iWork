## 目标

用户能用拖入、粘贴、选择三种方式附加图片和文件；凭据文件先提示再附加，私钥一律拒绝。

## 范围

**做**

2. **附件**（原范围 2，9.2）：后台服务再查一次 20MB 上限；算 sha256；仓库内的文件只记路径引用，其余复制进附件区 `attachments/`；图片转成 ACP image 块（运行时不支持时提示），其他文件转成 resource_link（指向只读区里的副本）；凭据目录里的文件返回「需确认」，确认后内容嵌进消息、副本存 `private/`，私钥拒绝（9.2 第 3a 条）。

**不做**：亲手执行（T10e）、本机导入的 MCP 密钥（T10f）。

## 验收标准

1. 附件（原验收 3，AC33）：拖入、粘贴、选择三种方式的图片和文件都送达运行时；仓库外的文件能被 Read 和 `cat` 读到、不触发询问，写入被拒；导入技能里的脚本能执行、不能修改；附加的 `~/.npmrc` 不出现在只读区；运行时不支持图片时界面有提示。附加 `~/.npmrc` 先提示、确认后送达；附加 `id_rsa` 和 `*.pem` 被拒绝（AC36）。
