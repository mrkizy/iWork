- **依赖**：T06、T10a
- **依据**：M1 技术设计 9.5、4a；需求 FR20、AC35；AGENTS.md「安全不变量」（不读取、不保存、不转发凭据）

## 目标

Claude Code 首次接入时，用户能把本机的 MCP 和技能导入 iWork；密钥只进系统钥匙串。

## 范围

**做**

4a. **本机导入**（原范围 4a，9.5、FR20）：Claude Code 首次接入时发现并列出本机的 MCP、技能、插件（只取技能和 MCP），提示一次；勾选导入；MCP 密钥重新填写，存系统钥匙串；设置 › 运行时 提供再次导入的入口，不弹窗、不显示红点。开会话时把导入的 MCP 经 ACP `session/new` 的 `mcpServers` 透传给运行时（T05 移交）：需要给端口的 `McpServerRef` 补启动配置（stdio 的命令、参数、环境变量名；http 的地址、请求头名，只加字段），密钥值不进端口，由适配器从 SecretStore 取。
- **SecretStore**（原范围 2a 的最后一句挪到这里）：MCP 密钥经 `iwork-host` 的 SecretStore 存进系统钥匙串（4a）。

**不做**：插件导入。

## 验收标准

1. 本机导入（原验收 5a，AC35）：首次接入时提示一次，重启后不再提示；设置入口可以再次导入；导入的 MCP 和技能出现在会话的 `system/init` 里，没导入的不出现；数据库和日志里检索不到 MCP 密钥明文。
