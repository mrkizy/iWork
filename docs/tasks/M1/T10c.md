## 目标

用户能用多种方式把项目加进来，加完不用任何配置就能和 iWork 对话。

## 范围

**做**

3. **添加项目**（原范围 3，9.3）：入口三种，方式三种（打开文件夹、克隆、新建项目）；新建和克隆默认放在 `~/iWork/projects/`，设置里可以改；先 `detect`，已知的项目直接跳转，没受版本控制的提示并可一键初始化；克隆有进度；AGENTS.md 草稿由 iWork 跑一个只读回合产出，以卡片展示，用户确认后由后台服务写文件；写 `.iwork/project.toml`、登记、进入新对话；移除项目不改动仓库内容。

**不做**：多成员。

## 验收标准

1. 新建项目后不用任何配置就能和 iWork 对话（原验收 1，AC21）。
2. 添加项目（原验收 4，AC34）：本机文件夹、Git 克隆、拖入、新建项目四种方式都能用；新建和克隆默认落在可配置的默认目录下；非 git 目录有提示并可初始化；重复添加跳转到已有项目；移除后仓库内容不变（对比文件哈希）。
3. AGENTS.md 草稿（原验收 5）：确认之前仓库里没有这个文件；确认后由后台服务写入。
