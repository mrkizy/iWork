# iWork 设计系统（M1）

从设计画布《iWork 产品形态原型》（风格定稿：底色 1，浅色 / 深色）导出，供客户端直接引用。规则说明以 `../ui-m1.md` 为准，本目录是它的可用素材。画布、`ui-m1.md` 与本目录不一致时：先看需求文档，再看画布，最后看本目录。

预览：`preview.png`（浅色与深色），或在浏览器里打开 `preview.html`。

## 文件

| 文件 | 内容 |
| --- | --- |
| `tokens.css` | 颜色令牌（浅色 / 深色，随 `data-theme` 或系统切换），以及字体、字号、圆角、阴影、布局宽度 |
| `motion.css` | 头像动效（悬停、戳一下、生气、浮动、弹出）、正在输入的点、“搞定”印章；减少动态效果与轻松元素开关的停用规则 |
| `characters/*.svg` | 13 个助手形象 × 15 种表情，共 195 个 SVG |
| `icon/iwork-icon-white-*.png` | 应用图标（白底，256 / 512 / 816），圆角由界面加 |
| `preview.html`、`preview.png` | 预览 |

## 颜色与主题

- 组件只引用 `tokens.css` 里的变量，不写死颜色。变量的用途见 `ui-m1.md` 3.2。
- 主题切换：在根元素上设 `data-theme="light"` 或 `"dark"`；不设时跟随系统。
- 状态色：`--okBg/--okTx`（成功）、`--warnBg/--warnTx/--warnBd`（待处理、越界）、`--blkBg/--blkTx`（拒绝、底线）。

## 字体与字号

Inter + Noto Sans SC，代码用 JetBrains Mono（`--font-sans`、`--font-mono`）。字号令牌从画布实际用值中整理：

| 令牌 | 值 | 用在 |
| --- | --- | --- |
| `--fs-display` | 30px | 首页“要做点什么？” |
| `--fs-title` | 19px | 弹窗标题 |
| `--fs-lg` | 16px | 品牌名、小标题 |
| `--fs-body` | 14.5px | 对话正文（行高 1.75） |
| `--fs-md` | 13.5px | 侧栏项、卡片正文、菜单项 |
| `--fs-sm2` | 12.5px | 按钮、标签、工具栏 |
| `--fs-sm` | 12px | 说明文字、时间戳、分组标题 |
| `--fs-xs` / `--fs-2xs` | 11px / 10px | 徽标、气泡、角标 |

圆角：`--r-xs` 6、`--r-sm` 8（按钮）、`--r-md` 10（输入框、代码块）、`--r-lg` 12（对话内卡片）、`--r-xl` 14（菜单）、`--r-2xl` 18（弹窗、主输入框）、`--r-pill`。

状态（文件名后缀）与成员状态的对应，由后台服务随 `ViewPatch` 下发（技术设计 9.7），网页层不自行判断：

| 后缀 | 状态 | 何时显示 | 配合的动效 |
| --- | --- | --- | --- |
| `idle` | 空闲 | 没有进行中的回合 | 无 |
| `work` | 工作中 | 回合进行中 | `.iw-float` |
| `wait` | 等你 | 有待审批或亲手执行卡片（待回答改用 `confused`，2026-11-12） | 无 |
| `done` | 完成 | 回合正常结束后保持数秒，再回到空闲 | `.iw-pop`（出现时一次） |
| `hover` | 悬停 | 鼠标悬停时替换当前图形 | `.iw-ch:hover` 的蹦跳与“嗨” |
| `sorry` | 出错（做错事：眼睛往下瞟、尴尬抿嘴、头顶一滴汗） | 最近一个回合失败、且没有等你处理的事；用户再发消息、新回合开始后换回对应状态（2026-11-11 加，见 `ui-m1.md` 2a 第 13 条） | 无（不浮动、不弹跳） |
| `confused` | 疑惑（眉毛一高一低、头顶漩涡） | 助手向你提问、有待回答卡片（2026-11-12 加，见 `ui-m1.md` 2a 第 14 条） | 无 |
| `tired` | 没电（半睁眼、头顶电池见底） | 该助手所用运行时的本机额度用完，且没有进行中的回合；额度恢复后换回 | 无 |
| `sleep` | 瞌睡（闭眼、头顶 Z） | 空闲超过 30 分钟（无进行中回合、无等你处理的事、未出错）；有新消息或新回合开始即换回 | 无 |
| `angry` | 假装生气 | 2 秒内连戳 3 次，持续约 1.5 秒后回到原状态 | `.iw-angry` |
| `think` / `surprised` / `love` / `cool` / `shy` | 彩蛋：思考 / 惊讶 / 喜欢 / 得意 / 害羞 | M1 不触发，只入库素材。以后接入时归“轻松元素”，关闭后不出现（设想：道谢 → 喜欢，一批任务全部完成 → 得意，被夸 → 害羞） | — |

状态冲突时只显示一个，优先级：等你 > 疑惑 > 工作中 > 没电 > 出错 > 完成 > 瞌睡 > 空闲；悬停与假装生气是客户端互动，临时覆盖当前表情。

SVG 结构：每个文件都分成 `.iw-body`、`.iw-cheeks`、`.iw-eyes`、`.iw-mouth`、`.iw-extra` 五组。颜色写成 `var(--ch1, 默认值)` 这种形式：内联进页面时跟随主题，单独打开时用默认值。

推荐用法：把同一个助手的当前状态图形与 `hover` 图形内联在同一个容器里：

```html
<span class="iw-ch iw-float">
  <svg class="iw-n">…work…</svg>
  <svg class="iw-h">…hover…</svg>
</span>
```

**戳一下与生气**：点击时给容器加 `.iw-poke`，动画结束后移除。客户端记录最近 2 秒内的点击次数，到 3 次时换成 `angry` 图形并加 `.iw-angry`，1.5 秒后恢复。戳头像不触发打开对话以外的任何业务操作。

**眼睛跟随（只限侧栏）**：
- 只监听侧栏容器的 `pointermove`，用 `requestAnimationFrame` 合并，每帧最多计算一次。
- 对每个头像，按“鼠标相对头像中心的方向”算出偏移，长度不超过 1.5px，只写到该头像 `.iw-eyes` 的 `transform`。
- 鼠标离开侧栏、窗口失去焦点、系统开启减少动态效果、轻松元素开关关闭时，清除偏移。
- 对话区等其他位置的头像不跟随。

## 动效与停用

| 类 | 时长与曲线 | 用途 |
| --- | --- | --- |
| `.iw-ch:hover` | 0.5s，cubic-bezier(.3,1.7,.5,1) | 悬停蹦一下，头顶“嗨” |
| `.iw-poke` | 0.45s，同上 | 戳一下 |
| `.iw-angry` | 1.5s，ease-in-out | 假装生气的抖动 |
| `.iw-float` | 2.2s，循环 | 工作中 |
| `.iw-pop` | 0.6s | 完成时弹一下 |
| `.iw-stamp` | 0.35s | “搞定”印章盖下 |

- 动画只用 `transform` 与 `opacity`，不得拖慢 16ms 帧。
- 系统开启“减少动态效果”时，`motion.css` 自动停用全部动画。
- 设置里关闭“轻松元素”（`playful_ui`）时，给根元素加 `.iw-playful-off`：不盖章、头像不浮动、不跳、不弹“嗨”、眼睛不跟随，表情仍随状态变化。
- 审批、越界、拒绝、亲手执行卡片与确认框上，不出现任何轻松元素（`ui-m1.md` 3.4）。
